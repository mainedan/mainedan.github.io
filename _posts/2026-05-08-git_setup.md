### Git Setup & Command Reference Guide

#### Setting Up SSH for Git
To securely connect to GitHub using SSH, follow these steps to generate an SSH key and configure your GitHub account.

##### Step 1: Generate an SSH Key
*   **Open Terminal or Command Prompt:**
    *  On Windows, you can use PowerShell or Command Prompt.
*   **Run the SSH Key Generation Command:**
    *  Use the following command to create a new SSH key:
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```
*  Replace "your_email@example.com" with your actual email address.
*   **Follow the Prompts:**
    *  You will be asked where to save the key. Press Enter to accept the default location.
    *  Optionally, set a passphrase for added security.

##### Step 2: Add the SSH Key to the SSH Agent
*   **Start the SSH Agent:**
    *  Run the following command to ensure the SSH agent is running:
```bash
eval "$(ssh-agent -s)"
```
*   **Add Your SSH Key:**
    *  Use the command below to add your SSH key to the agent:
```bash
ssh-add ~/.ssh/id_ed25519
```
*  Adjust the path if you saved your key in a different location.

##### Step 3: Add the SSH Key to Your GitHub Account
*   **Copy the Public Key:**
    *  Use the following command to copy your public key to the clipboard:
```bash
cat ~/.ssh/id_ed25519.pub
```
*  Alternatively, open the file in a text editor and copy its contents.
*   **Log into GitHub:**
    *  Go to your GitHub account settings.
*   **Add a New SSH Key:**
    *  Navigate to SSH and GPG keys.
    *  Click on New SSH key, paste your public key, and save it.

##### Step 4: Test Your SSH Connection
*  Run the following command to test the connection:
```bash
ssh -T git@github.com
```
*  You should see a message confirming a successful connection.

By following these steps, you will have set up SSH for Git, allowing secure communication with GitHub.

#### Setting Up Your Git Username and Email
To properly configure your Git environment, you need to set your username and email address. This information is crucial as it is associated with every commit you make.

##### Global Configuration
To set your username and email globally (for all repositories on your system), use the following commands in your terminal:
*   **Set your username:**
```bash
git config --global user.name "Your Name"
```
*   **Set your email:**
```bash
git config --global user.email "you@example.com"
```

##### Local Configuration
If you want to set a different username or email for a specific repository, navigate to that repository's directory and run:
*   **Set your username:**
```bash
git config user.name "Your Name"
```
*   **Set your email:**
```bash
git config user.email "you@example.com"
```

##### Verifying Your Configuration
To check if your username and email have been set correctly, use the following command:
```bash
git config --list
```
This will display all your Git configuration settings, including the username and email.

##### Important Notes
*  The global settings apply to all repositories unless overridden by local settings.
*  Changes made will only affect future commits; past commits will retain the original information.

#### Git Command Cheat Sheet

##### 1. Getting Started & Initial Branch Setup
*   **Start a new repository (default initial branch):**
```bash
git init
```
*   **Start a new repository with initial branch `main`:**
```bash
git init -b main
# OR
git init --initial-branch=main
```
*   **Set `main` as the global default initial branch:**
```bash
git config --global init.defaultBranch main
```
*   **Rename an existing branch (e.g., `master` to `main`):**
```bash
git branch -m master main
```
*   **Clone an existing repository:**
```bash
git clone <url>
```

##### 2. Configure Git
*   **Set a config option (local repository):**
```bash
git config user.name 'Your Name'
```
*   **Set option globally across system:**
```bash
git config --global user.name 'Your Name'
```
*   **Set global default branch to `main`:**
```bash
git config --global init.defaultBranch main
```
*   **Add a command alias:**
```bash
git config alias.st status
```
*   **See all configuration options:**
```bash
man git-config
```

##### 3. Prepare to Commit (Staging)
*   **Add untracked file or unstaged changes:**
```bash
git add <file>
```
*   **Add all untracked files and unstaged changes:**
```bash
git add .
```
*   **Choose which parts of a file to stage interactively:**
```bash
git add -p
```
*   **Move or rename a file:**
```bash
git mv <old> <new>
```
*   **Delete a file:**
```bash
git rm <file>
```
*   **Stop tracking a file without deleting it locally:**
```bash
git rm --cached <file>
```
*   **Unstage a single file:**
```bash
git reset <file>
# OR
git restore --staged <file>
```
*   **Unstage everything:**
```bash
git reset
# OR
git restore --staged .
```
*   **Check workspace status:**
```bash
git status
```

##### 4. Make Commits
*   **Make a commit (opens editor for message):**
```bash
git commit
```
*   **Make a commit with an inline message:**
```bash
git commit -m 'message'
```
*   **Commit all modified and deleted (unstaged) files:**
```bash
git commit -am 'message'
```
*   **Amend last commit (message or add staged files):**
```bash
git commit --amend
```

##### 5. Branch Management & Switching
*   **Switch branches:**
```bash
git switch <name>
# OR
git checkout <name>
```
*   **Create and switch to a new branch:**
```bash
git switch -c <name>
# OR
git checkout -b <name>
```
*   **List local branches:**
```bash
git branch
```
*   **List branches sorted by most recent commit date:**
```bash
git branch --sort=-committerdate
```
*   **Rename current branch (e.g. `master` to `main`):**
```bash
git branch -m master main
```
*   **Delete a branch safely:**
```bash
git branch -d <name>
```
*   **Force delete an unmerged branch:**
```bash
git branch -D <name>
```

##### 6. Diff Staged / Unstaged Changes & Commits
*   **Diff all staged and unstaged changes:**
```bash
git diff HEAD
```
*   **Diff only staged changes:**
```bash
git diff --staged
```
*   **Diff only unstaged changes:**
```bash
git diff
```
*   **Show diff between a commit and its parent:**
```bash
git show <commit>
```
*   **Diff two specific commits:**
```bash
git diff <commit1> <commit2>
```
*   **Diff changes in a single file since a specific commit:**
```bash
git diff <commit> <file>
```
*   **Show diff summary statistics:**
```bash
git diff <commit> --stat
git show <commit> --stat
```

##### 7. Referencing Commits
When `<commit>` is required, you can use:
*   **Branch name:** `main`
*   **Tag name:** `v0.1`
*   **Commit hash/ID:** `3e887ab`
*   **Remote branch:** `origin/main`
*   **Current commit:** `HEAD`
*   **Relative commits:** `HEAD^^^` or `HEAD~3` (3 commits prior)

##### 8. Discard Changes, Edit History & Reflog
*   **Discard unstaged changes to a file:**
```bash
git restore <file>
# OR
git checkout <file>
```
*   **Discard all staged and unstaged changes to a file:**
```bash
git restore --staged --worktree <file>
# OR
git checkout HEAD <file>
```
*   **Discard all staged and unstaged changes in repository:**
```bash
git reset --hard
# OR
git restore --staged --worktree .
```
*   **Remove untracked files:**
```bash
git clean
```
*   **Stash all staged and unstaged changes:**
```bash
git stash
```
*   **Undo last commit preserving working tree changes (Soft Un-commit):**
```bash
git reset HEAD^
```
*   **Amend current commit message or add staged changes:**
```bash
git commit --amend
```
*   **Interactive Rebase (Squashing / Editing recent commits):**
```bash
git rebase -i HEAD~5
# In editor, change "pick" to "fixup" or "squash" to combine commits
```
*   **Emergency Recovery with Reflog (Undo failed rebase or lost commits):**
```bash
git reflog <branchname>
git reset --hard <commit-id>
```

##### 9. Advanced Branch Combination Strategies
*   **Combine via rebase (linear history):**
```bash
git switch feature
git rebase main
```
*   **Combine via standard merge:**
```bash
git switch main
git merge feature
```
*   **Combine via squash merge (condense branch into single commit):**
```bash
git switch main
git merge --squash feature
git commit
```
*   **Bring branch up to date (fast-forward merge):**
```bash
git switch main
git merge feature
```
*   **Copy a specific commit to current branch:**
```bash
git cherry-pick <commit>
```

##### 10. Syncing & Remote Operations
*   **Push main branch to remote origin:**
```bash
git push origin main
```
*   **Push current branch to its tracking branch:**
```bash
git push
```
*   **Push a new local branch and set upstream tracking:**
```bash
git push -u origin <name>
```
*   **Safely force push (prevents overwriting remote work):**
```bash
git push --force-with-lease
```
*   **Push tags to remote:**
```bash
git push --tags
```
*   **Fetch remote changes without updating local branches:**
```bash
git fetch origin main
```
*   **Fetch and rebase current branch on top of remote:**
```bash
git pull --rebase
```
*   **Fetch and merge into current branch:**
```bash
git pull origin main
# OR
git pull
```

##### 11. Code Archaeology & History Inspection
*   **View commit history:**
```bash
git log main
git log --graph main
git log --oneline
```
*   **Show commits that modified a specific file:**
```bash
git log <file>
```
*   **Show file history across renames:**
```bash
git log --follow <file>
```
*   **Find commits that added or removed specific text:**
```bash
git log -G 'search text'
```
*   **Show line-by-line author attribution:**
```bash
git blame <file>
```

##### 12. Restore Files & Remotes
*   **Restore a file version from a specific commit:**
```bash
git checkout <commit> <file>
# OR
git restore <file> --source <commit>
```
*   **Add a remote repository:**
```bash
git remote add <name> <url>
```

##### 13. Important Configuration Files
*   **Local repository configuration:** `.git/config`
*   **Global user configuration:** `~/.gitconfig`
*   **Ignored patterns list:** `.gitignore`
